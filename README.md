# Duc Hm - Software Development Engineer Portfolio

A premium, modern, and high-performance portfolio website designed for showcasing software engineering expertise and freelance digital solutions.

## 🚀 Overview

This portfolio is built with a focus on **technical precision** and **clean aesthetics**. It features a "glassmorphism" design, smooth animations, and is fully optimized for client acquisition.

## ✨ Features

- **Multi-language Support**: Seamlessly switch between English and Vietnamese.
- **Glassmorphism Design**: Modern, premium UI using CSS variables and glass effects.
- **Digital Solutions Grid**: Focused on freelance services (Web, Mobile, ERP/CRM, Security, API Integrations).
- **Industry Experience Showcase**: Highlights professional work in MedTech, FinTech, InsurTech, and Manufacturing.
- **Responsive & Dynamic**: Optimized for all devices with scroll-reveal animations.
- **Action-Oriented**: Direct Zalo and Email integration for instant client connection.

## 🛠️ Tech Stack

- **Core**: HTML5, Semantic Web
- **Styling**: Vanilla CSS3 (Custom Design System, Variable-based)
- **Logic**: Vanilla JavaScript (ES6+ Modules)
- **Icons**: Boxicons
- **I18n**: Custom dynamic translation engine
- **Build Tool**: Vite (recommended) / Static Hosting

## 📦 Getting Started

### Prerequisites

- Node.js (for development environment)

### Installation

1. Clone the repository
2. Install dependencies:
   ```powershell
   npm install
   ```

### Development

To run the project locally with hot-reloading:

```powershell
npm run dev
```

### Build

To generate a production bundle:

```powershell
npm run build
```
